--------------
Simulation mode is the default. Production writes are disabled. The included
.env contains placeholder/demo secrets and no provider API key. Side-effecting
MCP tools require a signed human approval, matching incident/action claims and a
restart-stable idempotency key. A failed action must add evidence and return to
